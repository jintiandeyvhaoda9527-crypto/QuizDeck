# Roadmap

The roadmap records intended work, not a promise of delivery. Completed behavior is documented in the README and release notes.

## v0.2 — Bilingual foundation

- Chinese and English UI with a saved language preference.
- English Excel header and question-type aliases.
- Localized AI output-language instruction and key error messages.
- Two Android language variants built from the same source.
- Narrow-screen checks for longer English labels.

## v0.3 — Classification quality

- Candidate semantic duplicate and near-duplicate detection.
- Optional role, department, topic, difficulty, and risk metadata templates.
- Reusable synthetic evaluation fixtures for batch classification.
- Better partial-batch recovery and provider compatibility diagnostics.

## v0.4 — Adaptive review

- Optional AI-assisted review suggestions based on local mistake patterns.
- Explainable recommendations that cite question IDs and remain user-controlled.
- Export and import of anonymized learning plans.

## Non-goals for the current client

- Mandatory cloud accounts or centralized employee tracking.
- Automatic publishing of AI output into formal assessments.
- Bundled provider credentials or subsidized end-user inference.
- Claims that any deployment can provide absolute data-leak prevention.
